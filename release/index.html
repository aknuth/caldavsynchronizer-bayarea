Requirements

  • Windows 10 or 11
  • Classic Outlook 2016 or later, or Microsoft 365 for desktop. The new Outlook for Windows doesn't support this add-in; switch back with the toggle at the top right.
  • Your mailbox set up in Outlook as an IMAP account, with the password saved.

Install

  1. Close Outlook.
  2. Unzip the download and run setup.exe. It installs .NET Framework 4.8 and the Office runtime first, if needed.
  3. Start Outlook, open the CalDav Synchronizer tab and click Set up calendars. Your calendars and address books are set up automatically.

To update later: CalDav Synchronizer → About → Check for updates. The installer replaces the old version and keeps your settings.
